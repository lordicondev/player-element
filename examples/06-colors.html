Examples

Colours

Colours from the colors attribute or from CSS, and current-color for an icon that takes the colour of the text. 

<lord-icon src="…">

The icon's own colours.

colors="primary:#fdd394,secondary:#03a9f4"

Colours by name: any hex value or CSS colour name.

--lord-icon-primary: #009688

A colour from CSS.

colors="primary:#b73a3a"
--lord-icon-primary: #3a7db7

CSS wins over the attribute.

current-color

Every part of the icon takes color, like text. Hover the row.
