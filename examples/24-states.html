States in CSS

CSS sees where an icon is: :state(waiting), loading, ready, error, intro and playing. 

lord-icon { opacity: 0 }
lord-icon:state(ready) { opacity: 1 }

Fades in once ready, after a second and a half.

lord-icon:state(error) { … }

The icon cannot load: the page shows it.

button:has(lord-icon:state(playing)) { … }

Click it: the button is marked while its icon plays.
